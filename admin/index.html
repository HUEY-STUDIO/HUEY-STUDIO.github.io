1 · 로그인

이 저장소(HUEY-STUDIO/HUEY-STUDIO.github.io)에 쓰기 권한이 있는 본인 GitHub 계정으로 Fine-grained personal access token을 새로 만드세요. Repository access → Only select repositories → 이 저장소만 선택, Permissions → Contents → Read and write 로 설정하면 됩니다. 토큰은 이 브라우저의 로컬 저장소에만 저장되고 GitHub API로만 전송됩니다 — 다른 사람과 공유하지 마세요. 이 페이지는 검색엔진에 노출되지 않지만 URL 자체를 아는 사람이라면 누구나 열 수 있으니, 실제 편집 권한은 토큰을 가진 사람에게만 있습니다.
